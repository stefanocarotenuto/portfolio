# stefanocarotenuto.it

Personal page of Stefano Carotenuto, designer and street photographer in Milan.
Live at [stefanocarotenuto.it](https://stefanocarotenuto.it).

The five photos under "In strada" come from [flaneurat.work](https://www.flaneurat.work/), which refreshes them every time the diary is published: nothing to change here.
